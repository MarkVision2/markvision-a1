# MarkVision — рекламное видео (таргетинг-оффер)

Вертикальное видео 9:16 (1080×1920, 30 fps, ~32 c) с озвучкой по сценарию.

## Файлы
- `markvision_ad.mp4` — готовое видео с озвучкой.
- `voice.mp3` — дорожка озвучки.
- `script.txt` — текст сценария (озвучка).
- `subs.ass` — тайминги и стиль текста на экране (libass).
- `build_video.py` — скрипт сборки (озвучка + анимированный текст + фон → mp4).

## Как пересобрать
```bash
pip install imageio-ffmpeg
# Озвучка (офлайн, espeak-ng):
espeak-ng -v ru -s 158 -p 42 -g 4 -f script.txt -w voice_raw.wav
# (опционально нормализация в voice.mp3 — см. историю команд)
python3 build_video.py
```

## Замечание по озвучке
Озвучка сгенерирована офлайн-движком **espeak-ng** (звучит «роботизированно»).
Нейросетевые голоса были недоступны в окружении:
- higgsfield — бесплатный план блокирует генерацию (`not_enough_credits`);
- ImagineArt — не авторизован (401);
- Microsoft edge-tts — хост `speech.platform.bing.com` заблокирован egress-политикой.

Чтобы заменить на премиальный нейроголос: пополнить кредиты higgsfield
(модель `seed_audio`, голоса Vlad/Roman) или авторизовать ImagineArt, затем
подставить новый `voice.mp3` и перезапустить `build_video.py`.
