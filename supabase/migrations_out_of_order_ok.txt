# Миграции «раньше последней записи в учёте», которые разрешено ПРИМЕНИТЬ
#
# Отличие от migrations_baseline_applied.txt: там версии, которые уже на проде
# и их надо только записать в учёт. Здесь — версии, которые деплою разрешено
# реально выполнить (`db push --include-all`), несмотря на то что они датированы
# раньше последней записи.
#
# Такой файл нужен, потому что CLI не применяет out-of-order миграции без явного
# флага, и правильно делает: применить их молча — значит выполнить по проду
# произвольный старый SQL. Список делает это решением человека, а не побочным
# эффектом деплоя. Версия, которой нет ни здесь, ни в базовой линии,
# останавливает деплой.
#
# Класть сюда можно только миграцию, безопасную при повторном прогоне:
#   - CREATE OR REPLACE FUNCTION / VIEW, либо DROP ... IF EXISTS перед CREATE;
#   - CREATE TABLE / INDEX только с IF NOT EXISTS;
#   - ADD CONSTRAINT только после DROP CONSTRAINT IF EXISTS;
#   - DML либо отсутствует, либо идемпотентен по условию.
#
# После применения версия попадает в учёт, и деплой её больше не трогает —
# строку можно оставить, она станет безобидной.
