# Справочник блоков лендинга

## Стандартная структура (порядок по конверсии)

1. **Hero** — первый экран, главный оффер
2. **Social proof** — сразу под hero для доверия
3. **Problem** — усиление боли
4. **Solution** — продукт решает
5. **How it works** — демистификация процесса
6. **Results / Cases** — доказательства
7. **Offer stack** — что входит + цена + гарантия
8. **FAQ** — закрытие возражений
9. **Final CTA** — последняя точка входа
10. **Footer** — контакты + юридические

---

## Опциональные блоки (добавлять по задаче)

### Quiz / Calculator
- Когда: B2B, сложный продукт, нужна персонализация
- Где: обычно между Hero и Problem, или как отдельная воронка

### Сравнение с конкурентами / альтернативами
- Когда: активная конкуренция в нише
- Где: после How it works
- Формат: таблица "мы vs конкурент vs ничего не делать"

### Таймлайн / процесс
- Когда: долгий продукт (курс, услуга с этапами)
- Где: вместо или после How it works
- Формат: неделя 1 / неделя 2 / ...

### Личность/команда
- Когда: экспертный продукт (консалтинг, обучение)
- Где: между Solution и Results
- Формат: фото + регалии + одна история

### Видео-отзывы / UGC
- Когда: есть сильный контент от реальных клиентов
- Где: в блоке Results или отдельным блоком
- Формат: плитка видео + текст отзывов

### Scarcity / urgency
- Когда: есть реальный дедлайн/лимит
- Где: перед оффером или на hero
- ВАЖНО: не фальшивый. Ложная срочность выжигает доверие.

## Правила для Hero-блока

### H1 должен содержать:
- Конкретный результат
- ИЛИ для кого
- Опционально — за сколько времени

**Плохо**: "Лучший курс по маркетингу"
**Хорошо**: "Первые 10 клиентов из таргета за 30 дней — для начинающих нутрициологов"

### Под H1 — H2/подзаголовок:
- Закрывает ГЛАВНОЕ возражение
- Или уточняет механизм

### CTA на hero:
- Одна кнопка, одно действие
- Текст кнопки = действие + ценность ("Получить разбор", не "Отправить")

---

## Правила для Offer stack (блок BL7)

По Hormozi:
1. Сначала назвать ГЛАВНОЕ что получают
2. Потом разбить на компоненты — что входит
3. Для каждого компонента — ценность (если возможно — в деньгах)
4. Суммарная "цена если купить отдельно"
5. Реальная цена пакета
6. Гарантия как последнее
7. CTA

---

## Принципы текстов

- **2-е лицо**: "ты получишь", "ты узнаешь" — не "вы узнаете" в бытовых нишах
- **Вы** — в B2B и консервативных нишах (финансы, мед, юр)
- **Конкретность**: цифры > прилагательные ("10 клиентов" > "много клиентов")
- **Короткие предложения**: в hero и CTA — не больше 10 слов
- **Активный залог**: "получи" > "будет получено"
- **Избегать**: "уникальный", "лучший", "качественный" — слова-наполнители

---

## Mobile-first чеклист

- Hero влезает на один экран без скролла
- Кнопка CTA — не меньше 48px по высоте
- Текст — минимум 16px, желательно 18px
- Контраст — минимум 4.5:1
- Форма — 1 колонка, крупные поля
- Картинки — lazy-load, оптимизированные
- Нет горизонтального скролла
