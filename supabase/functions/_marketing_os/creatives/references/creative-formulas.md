# Формулы креативов

## 5 типов хуков (первые 3 секунды)

### Тип 1: Провокационный вопрос
*"Почему 90% [ЦА] так и не [достигли цели], даже пробуя [популярное решение]?"*
Работает на любопытство. Идеально для холодной аудитории.

### Тип 2: Шокирующая цифра
*"За 30 дней — [результат]. Без [болезненного процесса]."*
Работает на скептиков. Нужны реальные цифры, иначе выжигает доверие.

### Тип 3: История-триггер
*"2 года назад я [описание ситуации клиента]. Сегодня — [результат]."*
Работает на эмоциональное вовлечение. Главное — релевантная история.

### Тип 4: Прямое обращение к сегменту
*"Если ты [описание сегмента] — обязательно досмотри."*
Работает на отсечение нецелевых и фокус на своих.

### Тип 5: Демонстрация результата
[Первые 3 секунды — показать конечный результат без слов]
Работает на визуальных/instagram-like платформах.

---

## Структура 60-секундного видео (HPSCP)

- **H** (Hook, 0-3с) — стоп-скролл
- **P** (Problem, 3-15с) — боль + её усиление
- **S** (Solution, 15-35с) — продукт как герой, уникальный механизм
- **C** (Credibility, 35-50с) — доказательство (цифра/отзыв/кейс)
- **P** (Push, 50-60с) — CTA с одним действием

---

## Структура короткого видео (15-30с, Reels / Shorts)

- 0-1с — сильный визуал
- 1-5с — хук словом/текстом
- 5-20с — проблема + решение в одном
- 20-30с — CTA

**Важно:** на Reels/Shorts хук должен быть в первой секунде. Скип = смерть.

---

## Формулы заголовков для баннеров

1. **[Результат] за [время] без [страха]**
   *"10 кг за 3 месяца без жёстких диет"*

2. **Как [сегмент] [достигает результата] даже если [барьер]**
   *"Как мамы в декрете запускают бизнес с телефона"*

3. **[Цифра] [ЦА] уже [сделали действие]. Ты следующий.**
   *"2 300 нутрициологов уже работают с нами"*

4. **Прямое обещание + дедлайн**
   *"Минус 7 кг к лету — старт 15 мая"*

## Типы текстовых объявлений

### Тип A: Прямое предложение
```
[Результат] для [сегмента]
[Одно преимущество]
[CTA]
```

### Тип B: Через боль
```
Устал(а) от [боли]?
[Продукт] решает это за [время].
[CTA]
```

### Тип C: Через гарантию
```
[Результат] за [время].
Не получилось — вернём деньги.
[CTA]
```

## Матрица разнообразия гипотез

При создании 3 гипотез на сегмент — бери РАЗНЫЕ углы:

| Угол | Содержание |
|---|---|
| Боль | Через острую проблему, страх, стоимость бездействия |
| Мечта | Через желаемый результат, образ будущего |
| Противопоставление | "Не как у всех" / против конкурентов / против стереотипа |
| Новизна | Новый механизм / открытие / тренд |
| Социальное | Что скажут окружающие / статус / принадлежность |

**Правило**: на сегмент делаем 3 гипотезы из 3 разных строк таблицы. Не 3 хука через боль.

## Частые ошибки (не допускать)

- ❌ Хук про продукт ("Представляем наш новый курс...") — никто не будет смотреть
- ❌ Слишком общие обещания ("Поможем стать лучше") — нет конкретики = нет клика
- ❌ Слишком много в CTA ("Пройдите тест, подпишитесь и получите гайд") — одно действие
- ❌ Длинные предложения в видео — зрителю тяжело
- ❌ Одинаковые хуки во всех гипотезах — это не тест, а монотонность
