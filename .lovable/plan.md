## Что меняем

В `src/components/ads/CabinetRow.tsx` (карточка кабинета на странице /ads):

### 1. Кнопка справа в шапке кабинета
- **Текст**: «Подтянуть» → **«Получить статистику»**
- **Иконка**: `Download` (выглядит как «скачать») → **`BarChart3`** из lucide-react (значок графика — по смыслу подходит для получения статистики)
- **Tooltip (`title`)**: «Подтянуть статистику из Meta» → «Получить статистику из Meta»
- **Текст во время загрузки**: «Загрузка…» — оставляем
- На узких экранах (`sm:hidden`) текст по-прежнему скрыт, видна только иконка — увеличим кнопку немного, чтобы влез новый длинный текст на десктопе

### 2. Пункт в выпадающем меню (три точки)
- «Подтянуть статистику» → **«Получить статистику»**
- Иконку `RefreshCw` оставляем (она крутится при загрузке) — это ок для меню

### 3. Импорты
- Убираем `Download` из импортов lucide-react
- Добавляем `BarChart3`

## Что НЕ трогаем

- Логика `handleSync` и вызов `meta-daily-sync` уже работает корректно — оставляем как есть
- Состояния `syncing`, тосты успеха/ошибки, авто-`refresh()` после успеха — без изменений
- Авто-синк при добавлении кабинета в `Ads.tsx` — без изменений

## Проверка после правки

1. Открыть /ads → у каждой карточки кабинета справа кнопка с иконкой графика и текстом «Получить статистику»
2. Клик → спиннер + «Загрузка…», после успеха — тост с количеством дней/лидов/расходом, цифры в карточке обновляются
3. В меню «три точки» пункт называется «Получить статистику»
