
# Раздел «Контент завод» — формирование ТЗ по стилю креатива

## Проблема

Сейчас на шаге 3 пользователь выбирает стиль (UGC с людьми, До-После, Talking Head, Motion и т.д.), но в n8n уходит только `id` + `label` + `description` стиля и общий `prompt` пользователя. У нейросети-генератора нет конкретных **визуальных инструкций**: как именно снять «До-После», какое освещение в «Студийном», какой кадр у «Talking Head». Из-за этого результаты непредсказуемы.

## Цель

Для каждого из 9 стилей креатива и 7 стилей нейрофотосессии прописать чёткий «технический бриф» (референс), который автоматически дополняет пользовательское ТЗ и уходит в n8n структурированно + единым текстовым промптом.

## Архитектура

### 1. Новый файл `src/data/styleBriefs.ts`

Словарь по `StyleId` со структурой:

```ts
{
  id: "before_after",
  label: "До-После",
  // Короткий бриф для AI-генератора
  composition: "split-screen 50/50 вертикальный или горизонтальный, чёткая граница по центру",
  lighting: "одинаковый свет в обеих половинах, мягкий рассеянный",
  cameraAngle: "фронтально, тот же ракурс на 'до' и 'после'",
  subject: "одинаковый объект/человек/пространство в двух состояниях",
  mood: "контраст, трансформация, видимый прогресс",
  typography: "минимум текста, опционально подписи 'ДО' / 'ПОСЛЕ' крупно",
  colorTreatment: "'до' — приглушённое, 'после' — яркое, насыщенное",
  props: "—",
  references: ["трансформация продукта", "до/после ремонта", "результат услуги"],
  // Готовый промпт-шаблон, в который подставляется бриф пользователя
  promptTemplate:
    "Создай рекламный креатив в формате 'До-После'. " +
    "Композиция: split-screen с чёткой границей по центру (вертикальной или горизонтальной). " +
    "Левая/верхняя часть — состояние 'ДО' (проблема, приглушённые цвета). " +
    "Правая/нижняя — 'ПОСЛЕ' (решение, яркие насыщенные цвета). " +
    "Один и тот же ракурс и одинаковое освещение в обеих половинах. " +
    "Подпиши крупно 'ДО' и 'ПОСЛЕ'. " +
    "Контекст товара/услуги: {{userBrief}}",
  // Negative prompt — что не рисовать
  avoid: ["разные ракурсы в половинах", "несоответствие объектов", "много текста"],
}
```

Заполняется для всех 9 креативных стилей:
- **auto** — без жёсткого брифа, передаём список всех кандидатов
- **ugc_people** — вертикаль 9:16/4:5, селфи-ракурс, естественный свет окна, человек смотрит в камеру/держит товар, эмоция, минимум обработки
- **ugc_product** — продукт крупно, в руках или в бытовом контексте (стол, ванная, кухня), естественный свет, без людей в кадре
- **ugc_mixed** — комбинация: один кадр человек, один кадр макро продукта, единый колорист
- **motion** — кинетическая типографика, яркие градиенты, динамика, hint что для видео/анимации
- **studio** — белый/чёрный/градиентный фон, постановочный свет (3-точечный), продукт в центре, premium-look
- **talking_head** — портрет эксперта по плечи, нейтральный фон или office, контакт глазами, можно микрофон/наушники как атрибут
- **before_after** — см. выше
- **typography** — крупный bold-текст как герой, цифра/цитата/оффер, минимум графики, акцентный цвет

И для 7 нейро-стилей (business, lifestyle, studio, outdoor, fashion, sport, casual) — атрибуты гардероба, локации, освещения.

### 2. Функция `buildStyleBrief(styleId, userBrief, format, color, angles)` в том же файле

Возвращает:
```ts
{
  technicalBrief: string,    // готовый текстовый промпт (для AI-движка)
  structured: {...},         // объект с полями composition/lighting/etc
  avoid: string[],           // negative prompt
}
```

Подставляет:
- `{{userBrief}}` — текст пользователя из step1
- aspect ratio из step2
- язык текста на креативе
- основной цвет (если выбран не «АВТО») в `colorTreatment`
- ракурсы (для нейро) в `cameraAngle`

### 3. Обновление `CreateStep3.tsx` → `handleCreate`

В payload для каждого стиля добавить:

```ts
design: {
  ...,
  currentStyle: {
    id, label, description, auto,
    brief: structured,           // НОВОЕ: структурированный бриф
    technicalBrief: "...",       // НОВОЕ: готовый текст промпта
    avoid: [...],                // НОВОЕ: negative
  },
},
finalPrompt: technicalBrief,     // НОВОЕ верхнего уровня — то, что n8n шлёт в AI
```

`finalPrompt` — это склеенный текст: системные инструкции стиля + пользовательский бриф + параметры формата. Именно это поле читает n8n и кладёт в AI image generator.

### 4. Превью ТЗ перед отправкой

В `CreateStep3.tsx` под кнопкой «Создать» добавить раскрывающийся блок **«Посмотреть ТЗ перед отправкой»** (Collapsible). Внутри — для каждого выбранного стиля показать:
- иконка + название стиля
- текст `technicalBrief` в `<pre>` (моноширинный, можно скопировать)
- бэйджи: композиция, свет, ракурс, цвет

Это даёт пользователю прозрачность и возможность вернуться на step 1, если ТЗ кривое.

## Файлы для изменения

| Файл | Что |
|---|---|
| `src/data/styleBriefs.ts` | **Новый.** Словарь брифов по 16 стилям + функция `buildStyleBrief()` |
| `src/pages/CreateStep3.tsx` | Импорт `buildStyleBrief`, обогащение payload (`design.currentStyle.brief`, `design.currentStyle.technicalBrief`, `design.currentStyle.avoid`, `finalPrompt`); блок-превью ТЗ под кнопкой «Создать» |
| `src/lib/contentFactory.ts` | Без изменений (вебхук тот же, payload расширяется) |

Ничего в БД и edge functions не трогаем — это чисто фронтовая логика подготовки промпта.

## Что получит n8n

```json
{
  "task": "ad_creative",
  "prompt": "<пользовательский бриф>",
  "finalPrompt": "<готовый промпт со стилевыми инструкциями + пользовательский бриф + формат>",
  "design": {
    "currentStyle": {
      "id": "before_after",
      "label": "До-После",
      "brief": {
        "composition": "split-screen 50/50",
        "lighting": "...",
        "cameraAngle": "...",
        "typography": "...",
        "colorTreatment": "...",
        ...
      },
      "technicalBrief": "...",
      "avoid": ["разные ракурсы", ...]
    }
  },
  "format": { "aspect": "4:5", "lang": "ru", "variants": 7 }
}
```

В n8n достаточно взять `finalPrompt` и передать в AI generator — стилевые инструкции уже встроены.
