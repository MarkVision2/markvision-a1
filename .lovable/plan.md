## Что нужно

В разделе **Управление рекламой → Кампании** (компонент `CampaignGoalsBreakdown.tsx`):

1. **Поле «ROMI · FB Pixel» сейчас почти всегда `—`** — оно тянется из `meta_campaign_daily.revenue`, которое заполняется только если на сайте стоит настроенный пиксель Meta с событием `Purchase`. У вас этого нет → колонка бесполезна и сбивает с толку.
2. **Нет сквозной связки с реальной выручкой** из CRM. У вас уже есть `meta_creative_crm_daily` (выручка/продажи по `ad_id`), но на уровне кампаний эта агрегация не делается.
3. **Дизайн карточки можно сделать существеннее**: KPI плоские, нет визуальной иерархии, нет трендов, нет «здоровья» цели, мини-список кампаний выглядит как просто строки.

## Что сделаю

### 1. Связь с CRM (функциональное)

Расширяю хук `useMetaCampaigns` — добавляю параллельный запрос:
```
meta_creative_crm_daily → meta_creatives (для campaign_id)
```
Агрегирую `crm_sales`, `crm_revenue`, `crm_leads`, `crm_qualified` по `campaign_id` за период.

В `MetaCampaignRow` появятся:
- `crmSales`, `crmRevenue`, `crmLeads`, `crmQualified`
- `crmRomi = (crmRevenue - spend) / spend * 100`
- `crmAvgCheck`, `crmCps`, `crmProfit`

В `CampaignGoalsBreakdown` агрегирую те же поля по цели (goal bucket).

### 2. Замена колонки «ROMI · FB Pixel»

Вместо одной непонятной колонки — **«ROMI · CRM»** с реальными деньгами:
- Если `crmRevenue > 0` → показываю `+XXX%` (success/destructive), плюс мини-подпись «Выручка `1.2M ₸` · `28` продаж».
- Если CRM-данных нет, но есть pixel revenue → показываю pixel-ROMI с пометкой «pixel» (мелким шрифтом, чтобы было видно источник).
- Если ничего нет → элегантный пустой стейт «Подключите CRM-источники» с маленькой иконкой-ссылкой на раздел CRM.

На уровне кампании в раскрытом списке: добавляю чип «Продаж N · `750k ₸`» рядом с существующими.

### 3. Редизайн блока

Конкретные визуальные апгрейды (в рамках текущей dark + teal палитры — её не трогаю):

**Шапка цели:**
- Большая «здоровье»-полоска под названием: тонкий gradient-бар, разделённый на сегменты (показы → клики → заявки → продажи) с числами под каждым сегментом — это микро-воронка цели на одном взгляде.
- Бейдж «активные» заменяю на pill с количеством активных / общим (`3/8 активных`), цвет привязан к доле.
- Большой «Profit» chip справа: `+450 000 ₸` (зелёный) или `-120 000 ₸` (красный), с микро-стрелкой тренда, если есть данные за предыдущий период такой же длительности (через дополнительный запрос за prev-range).

**KPI grid:**
- Перехожу с 5 одинаковых ячеек на иерархию 2-3-2: главное (`Расход`, `Выручка CRM`) большим шрифтом слева, второстепенные (`Заявки`, `Цена`, `CTR`) компактнее справа, ROMI вынесен в правый верхний угол как акцент.
- Каждая числовая ячейка получает мини-sparkline (7 точек, daily) — забираю одним запросом `meta_campaign_daily` группируя по date.

**Кампании внутри:**
- Карточка кампании: тонкая прогресс-полоска `share of spend` сейчас уже есть — оставляю, но добавляю второй слой — `share of revenue` другим цветом, чтобы видеть «много тратит → мало продаёт» аномалии.
- Чипы метрик заменяю на компактный inline-grid с фиксированной шириной (сейчас они скачут).
- Hover → показываю кнопку «Открыть креативы», ведёт на `/ads?tab=creatives` с префильтром по campaign_id.

**Empty / inactive:**
- Когда `activeCount === 0` сейчас всё выглядит «прозрачно». Делаю явный диминутив + кнопку «Создать новую кампанию для этой цели» (открывает существующий `CreateCampaignDialog` с предзаполненным objective).

- `src/components/dashboard/CampaignGoalsBreakdown.tsx` — переработка `GoalCard`, `KpiCell`, `CampaignRow`. Новые подкомпоненты: `FunnelStrip`, `Sparkline`, `ProfitChip`.
