# Motion library — база вставок (b-roll кодом)

Каталог code-based моушн-вставок (`remotion/src/motion.tsx`). Цель — **разнообразие**
и **подбор по смыслу**: под каждую фразу берём шаблон, который её иллюстрирует, и не
повторяем один и тот же. Все — оверлеи поверх спикера; с `data.cover:true` уходят на
премиум-фон (SceneBackground) и заменяют кадр (голос продолжается).

Общие поля `data`: `accent` (HEX цвета вставки), `cover` (bool), `icon`/`icons` (см. набор ниже).
Палитра акцентов: orange `#FF7A18` · cyan `#22D3EE` · violet `#8B5CF6` · emerald `#34D399`
· amber `#FFC53D` · rose `#FB7185` · sky `#38BDF8`. **Меняй цвет от вставки к вставке.**

Набор иконок: `check globe apps layers award coin code bolt fire clock chart rocket target`.

## Шаблоны и когда применять (по смыслу)

| template | что показывает | брать под смысл (примеры фраз) | ключевые `data` |
|---|---|---|---|
| `kinetic-type` | крупное слово/связка, впрыгивает | титул, роль, панч, CTA — «IT-предприниматель», «вайб-кодинг», «места ограничены» | `words:[..]`, `accentIndex`, `icon` |
| `checklist-reveal` | список с иконками-плитками | перечисления — «сайты, приложения, платформы», «что автоматизировать» | `items:[..]`, `icons:[..]` |
| `number-counter` | цифра роллит вверх | деньги/метрики — «5 млн ₸», «10 часов», «+300%» | `value`, `suffix`, `label`, `icon` |
| `stat-grid` | ряд плиток икон+цифра | несколько выгод/метрик разом — «быстрее, дешевле, точнее» | `items:[{icon,value,label}]` |
| `fake-terminal` | окно «claude code», печать | про код/сборку — «собрал приложение», «ИИ пишет код» | `title`, `lines:[..]` |
| `fake-dashboard-bars` | растущие бары по годам | рост/тренд — «набирает популярность», «до/после» | `title`, `bars:[{label,value}]` |
| `timeline-steps` | нумерованные шаги | процесс — «как это работает», «3 шага» | `steps:[..]` |
| `quote-card` | крупная цитата на стекле | тезис/хук/обещание — «монтаж за 0 ₽» | `text` |
| `loading-to-done` | кольцо-прогресс → ✓ | ожидание→результат — «за пару минут готово» | `label`, `doneLabel` |
| `annotate-arrow-highlight` | обводка+подпись поверх спикера | указать на предмет/деталь в кадре | `x`,`y`(0..1), `label` |
| `vs-compare` | две колонки «vs» | сравнение — «вручную vs с ИИ» | `leftItems`,`rightItems` |

## Правила разнообразия
- В одном ролике **не повторять** один шаблон подряд; чередовать типы и цвета.
- ~половину ключевых моментов — `cover:true` (уход на фон), остальное — оверлеи поверх спикера.
- Текст в `kinetic-type` авто-ужимается под ширину; длинные слова дели на 2 строки через `words`.
- Слова, показанные вставкой, автоматически не дублируются в титрах (`Shorts916` их прячет).

## Разметка (per video)
Вставки живут в `work/<id>/inserts.json` (anchorWord/endWord + template + data). Подбор
шаблона под фразу — задача разметки (Claude): смотри транскрипт → под смысл фразы выбери
строку из таблицы выше → задай цвет/иконку из палитры. Дальше `shorts.py` → `audio.py`.
