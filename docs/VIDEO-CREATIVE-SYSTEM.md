# Video Creative System: подключение к MarkVision

Внешняя система производства вертикальных VoiceOver-креативов (`dengineproblem/video-creative-system-public`),
подключённая к платформе как ещё один контур производства. Подключено 6 сентября 2026.

## Лицензия — читать перед использованием

Репозиторий **не open source**. `LICENSE.md`: proprietary source-available, обладание кодом не даёт
права использовать, копировать, изменять и распространять его; использование разрешено только при
отдельной письменной коммерческой лицензии или активной подписке у правообладателя.

Отсюда два правила:
1. **Код этой системы не коммитится в репозиторий MarkVision.** Он живёт отдельной папкой вне репозитория.
   В git MarkVision попадает только этот документ и наши собственные мосты.
2. Перед боевым использованием в MarkVision нужна действующая лицензия у автора системы.

Remotion и провайдеры (ElevenLabs, Google Imagen/Veo) лицензируются и оплачиваются отдельно.

## Путь установки: почему не рядом с MarkVision

Изначально система стояла в `Новый проект MarkVision/video-creative-system` и `doctor.py` падал на
проверке `pipeline_root`, хотя путь визуально совпадал. Причина — кириллица в пути: macOS хранит
имена файлов в разложенной форме Unicode (NFD), bash и Python отдают разные формы, и побайтовое
сравнение пути не проходит. Поэтому система стоит по ASCII-пути без пробелов.

**Не переносить систему в путь с кириллицей** — сломается `doctor.py`, `smoke_test.sh` и всё, что
сверяет `VIDEO_PIPELINE_ROOT`.

## Мост в платформу

Система производит файл, MarkVision его публикует. Связка — публичный API проекта и MCP-сервер
`mcp/markvision/` (`docs/PUBLIC-API.md`):

1. `markvision_upload_media(file_path)` — финальный экспорт уходит в хранилище, возвращается `file_url`.
2. `markvision_create_publication({file_url, title, caption, hashtags, duration_sec})` **без**
   `group_id` и `account_ids` — видео принято, задания не созданы.
3. Раскладка по сети — на выбор:
   - `markvision_distribute({videos:[{id, topic_key}], batch_id, per_day: 3})` — пачка, один ролик
     в один аккаунт, ≤ 3 в сутки, одна тема в разные дни (`docs/TZ-content-factory-network.md`, §4.6);
   - `markvision_create_jobs(publication_id, {group_id, mode})` — один ролик во все аккаунты группы.

Дальше работает обычная очередь публикаций: слоты, окна аккаунтов, разгон, метрики, здоровье
(`docs/PUBLISHING-SYSTEM.md`, `docs/AUTOPOSTING-PLATFORM.md`).

## Место среди контуров производства

| Контур | Что делает | Формат |
|---|---|---|
| `content-factory` (скилл) | пачка роликов из трендов, аватар поверх анимации | `ReelsAvatar`, 9:16 |
| Reels-очередь | faceless-графика под ИИ-озвучку | `ReelsExplainer`, 9:16 |
| Монтаж съёмки | автомонтаж говорящей головы из реального видео | `Main169`, `Shorts916` |
| **Video Creative System** | VoiceOver-креативы: клипарты, инфографика, Veo/Imagen, LUFS-мастеринг | `kinetic_clipart_v4`, 9:16 |

Все четыре отдают файл в одну очередь публикаций MarkVision.

## Как запускать

Работа ведётся из Claude-сессии скиллами `video-*` (см. `AGENT_HANDOFF.md` в самой системе — это
её рабочий контракт). Точка входа для агента:

```bash
cd ~/video-creative-system && ./scripts/doctor.py
```

Основные ворота согласования, которые система требует не пропускать: сценарий → раскадровка →
превью сгенерированных кадров → голос → review-сборка → финал. Платную генерацию (Veo, Imagen)
не запускать без явного согласования.
