# Референс-стиль «overlay-reels» (говорящая голова, БЕЗ б-роллов)

Разбор эталонного рилса (robotoverlayv2): именно так система должна монтировать
«Монтаж съёмки». Никакого стока/футажа, только анимация Remotion поверх спикера.

## Что на экране
- **Спикер на весь кадр.** Вся графика — оверлеем поверх, спикера не закрываем
  полностью. Никаких full-cover сцен, никакого б-ролла.
- **Верхняя инфо-карточка (главная фишка).** Тёмная (#0E0F13) со скруглением ~28px,
  **неон-лаймовая рамка + свечение**. Занимает верх (~под safe-зоной, top ~90px).
  Внутри:
  - **лайм-чип** с коротким тегом (РОБОТ / 24/7 / БУСТ) + **заголовок с эмодзи**
    (🤖 ЗАМЕНЯЕТ:, ОТ ТВОЕГО ЛИЦА, 📈 ЧТО ПОЛУЧАЕШЬ);
  - **список, который НАКАПЛИВАЕТ пункты построчно** синхронно с речью (каждый
    пункт впрыгивает, когда спикер его произносит);
  - типы строк разные: эмодзи-буллеты (👀🔥🔁 Смотрит и лайкает сторис…),
    **iOS-тумблеры (вкл, лаймовые)**, **выделенная строка с галочкой** на лаймовом
    фоне (✅ БЕЗ НАКРУТКИ И РИСКА БАНА);
  - карточка **меняет секции** по ходу ролика (3–4 секции: проблема → что делает →
    что получаешь → результат).
- **Караоке-титры снизу** (safe-зона): тёмная пилюля со скруглением, **жирный
  БЕЛЫЙ UPPERCASE**, одна фраза за раз, **ключевые слова подсвечены лаймом прямо
  внутри строки** (не плашкой на слове, а цветом текста: «10 ТЫСЯЧ РАЗ», «БЕЗ
  НАКРУТКИ И РИСКА БАНА»).
- **Верхний край** — тонкая **неон-радужная полоса** (акцент бренда сверху).
- **Акцент — неон-лайм** (~#B4FF3A). У нас бренд оранжевый — берём СТРУКТУРУ, цвет
  оставляем свой (или даём под-бренд).

## Тайминг/ритм
- Пункт списка / фраза титра меняются каждые ~1.5–2.5 сек, синхронно со словами.
- Секция верхней карточки живёт ~6–10 сек (пока идёт её тема), потом свап на новую.
- Динамика постоянная, но кадр чистый: спикер + карточка сверху + титр снизу.

## Что из этого делаем в системе (план реализации)
1. **Новый постоянный оверлей `spec-card`** (Shorts916) вместо разовой вставки:
   верхняя карточка с секциями; пункты накапливаются по anchorWord каждого пункта;
   типы строк: `bullet` (эмодзи), `toggle` (вкл), `check` (выделенная строка).
   Разметка: секции с {tag, title, emoji, items:[{type, emoji, text, atWord}]}.
2. **Инлайн-подсветка в титрах** (новый `captionStyle: "highlight"`): ключевые
   слова красим акцентом ВНУТРИ фразы, фон-плашка одна на всю фразу (тёмная пилюля).
   Сейчас у нас плашка на каждом акцентном слове — добавить инлайн-режим.
3. **Эмодзи в строках** (рендер эмодзи в Remotion — через шрифт/twemoji).
4. **Верхняя радужная полоса** + опция под-бренда (лайм) в `brand.config.json`.
5. Спикер всегда виден: `spec-card` в layout `top` (не full), титры в safe-зоне.

## Итог
Стиль = «живой дашборд поверх говорящей головы»: сверху накопительная карточка-
чеклист с тумблерами/галочками и эмодзи, снизу караоке с инлайн-подсветкой ключевых
слов, неон-акцент. Без стока и б-роллов, вся анимация — Remotion.
