# TZ для Lovable — раздел «Контент-аналитика»

Скопируй и вставь это сообщение в Lovable одним промптом. В репозитории уже есть рабочая страница `src/pages/ContentAnalytics.tsx` и роут `/analytics/content` — Lovable должен **переоформить** её и доработать UX, не ломая хуки и логику.

---

## Контекст

В платформе уже есть «Сквозная аналитика» (`/analytics`) и «Воронка по креативам» (`/analytics/creatives`) — они про **платную** рекламу через Meta. Я хочу зеркальный раздел, но про **органический контент** (Instagram Reels).

### Бизнес-логика, которую нужно показать

Я публикую много Reels. Под каждым Reel я говорю аудитории: *«Напиши в комментариях/директ слово __<код-слово>__ и я скину ссылку»*. Дальше:

1. Зритель пишет код-слово в DM (Direct).
2. Бот отвечает короткой ссылкой (наша короткая ссылка `…/ig-organic-redirect?c=<short_id>`).
3. Зритель кликает — фиксируется `link_click`.
4. Лендинг с формой → лид падает в CRM.
5. Менеджер закрывает сделку — `paid=true`, `amount=...`.

Раздел должен показать **сквозную воронку**: **DM → клик → лид → продажа → выручка**, в разрезе каждого код-слова (и значит, каждого Reel).

## Где это в навигации

- Пункт «Контент-аналитика», иконка `Hash`, путь `/analytics/content`. Уже добавлен.

## Структура страницы

Реализована в `src/pages/ContentAnalytics.tsx`. Сохрани композицию блоков, можно усилить визуал, типографику, скелетоны и плотность таблицы.

### 1. Шапка (`PageHeader`)

- Иконка `Sparkles`.
- Title: «Контент-аналитика».
- Description: «Сквозная воронка органического контента: код-слово под Reels → DM → клик по ссылке → лид в CRM → продажа.»
- Справа: `PeriodPicker` + кнопка «Добавить код-слово» (открывает `Dialog`).

### 2. KPI-полоска (7 карточек)

Используй паттерн `KpiCard` уже из файла. Карточки слева направо:

| Иконка | Лейбл | Значение | Хинт |
|---|---|---|---|
| `MessageCircle` | DM с код-словом | `funnel.codewordDms` | за выбранный период |
| `Users` | Уникальных | `funnel.uniqueUsers` | по username |
| `MousePointerClick` | Кликов по ссылке | `funnel.linkClicks` | — |
| `Eye` | Лидов | `funnel.leads` | tone=`success` |
| `ShoppingBag` | Продаж | `Σ stats.sales` | tone=`success` |
| `Wallet` | Выручка | `Σ stats.revenue` (фмт `₸`) | tone=`success` |
| `TrendingUp` | DM → Лид | конверсия `%` | строка "Клик → Лид x%", tone=`warning` |

Адаптив: `grid-cols-2 md:grid-cols-4 xl:grid-cols-7`.

### 3. График-тренд

`ContentTrendChart` (`src/pages/content-analytics/ContentTrendChart.tsx`) — 3 area-series:
- DM в директ (primary),
- Клики (warning),
- Лиды (success).

По X — дни выбранного периода. Источник — `useInstagramOrganic(range).events`, агрегируем по `date`.

### 4. Таблица код-слов

Колонки (сортируемые, кликом на заголовок переключаем направление):

1. **Код-слово / Reel** — превью `thumbnailUrl` 40×40 + `#codeword` + ссылка на Reel (если есть).
2. **DM** — `codewordDms`.
3. **Уникальных** — `uniqueUsers` (приглушённый цвет).
4. **Клики** — `linkClicks`.
5. **Лиды** — `leads` (полужирный).
6. **Продажи** — `sales`.
7. **Выручка** — `revenue` в `₸` (выделить).
8. **CR** — `leads / codewordDms × 100%` (приглушённый).
9. Экшены — `Copy` (скопировать короткую ссылку `${SUPABASE_URL}/functions/v1/ig-organic-redirect?c=<short_id>`), `Switch active`, `Trash`.

Клик по строке → правый `Sheet` (дровер) с деталями по код-слову.

### 5. Drawer «Лиды по код-слову»

- 6 мини-карточек метрик: DM, Клики, Лиды, Продажи, Выручка, конверсия DM→Лид.
- Блок «Короткая ссылка» с кнопкой копирования.
- Список лидов: имя, телефон, источник, сумма (если `amount > 0`), бейдж «Оплачен» если `paid=true`, дата создания. Сортировка — новые сверху.

Источник лидов — хук `useCodewordLeads(codewordId)`.

### 6. Пустые состояния

- **Проект не выбран** — большой плейсхолдер «Выберите проект в верхней панели».
- **Нет код-слов** — кнопка «Добавить первое» с пояснением «Мы выдадим короткую ссылку для бота».
- **Нет лидов** в дровере — «Пока ни одного лида с этого код-слова».

### 7. Диалог «Новое код-слово»

Поля:
- **Код-слово** (обязательное, приводится к lower-case),
- **Ссылка на Reel** (опционально),
- **Target URL** — куда вести зрителя после клика по короткой ссылке. **К URL автоматически добавляются** `utm_source=instagram&utm_medium=organic&utm_campaign=<codeword>&cw=<codeword>` — это критично для атрибуции лида.
- **Превью Reels** (URL картинки),
- **Подпись / заметка**.

После сохранения короткая ссылка моментально доступна в таблице, можно копировать.

## Стиль и дизайн-система

- Цвета: `hsl(var(--success))` — главные акценты, `hsl(var(--warning))` — конверсии, `hsl(var(--primary))` — DM.
- Радиусы карточек — `rounded-2xl`, бордеры — `border-border/60`, фон — `bg-card/60`.
- Шрифт чисел — `tabular-nums`.
- Иконки `lucide-react`, размер 4×4 в кнопках, 8×8 в плашках KPI.
- Тёмная тема — уже работает через `next-themes`.
- Анимации появления — через класс `animate-fade-in-up` (`PageContainer` ставит автоматически).

## Что НЕ менять

- Сигнатуры хуков `useInstagramOrganic`, `useCodewordStats`, `useInstagramCodewords`, `useCodewordLeads` — данные приходят оттуда.
- Маршрут `/analytics/content` и lazy-импорты в `App.tsx` / `routePrefetch.ts`.
- SQL и edge-функции (`supabase/`).
