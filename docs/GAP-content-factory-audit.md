### 2.3 Дистрибуция (сеть аккаунтов)

Ключевое расхождение: **MarkVision построен на официальных API площадок** (Instagram Content Publishing, TikTok
Content Posting, YouTube Data, Threads) с OAuth-подключением собственных аккаунтов. План платформы
(`docs/AUTOPOSTING-PLATFORM-PLAN.md`, п. 1) прямо исключает браузерную автоматизацию и Multilogin. Система автора —
**покупные авторег-аккаунты на облачных телефонах** с ручной/автоматизированной публикацией через приложение.
Это два разных контура, и второго в MarkVision нет.
