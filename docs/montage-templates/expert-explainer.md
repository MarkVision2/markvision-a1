# Montage style: Expert Explainer

Референс: вертикальный кейс-ролик (~111 с, 9:16) с говорящей головой,
жёлтыми метриками сверху, караоке-титрами и частыми cover-сценами
(PiP спикера + карточка / схема / график по центру).

## Ритм
- Плотность: **1 визуальный акцент на 3–5 сек**, без дыр >5 сек.
- Чередование режимов:
  - ~55% — спикер на весь кадр + верхний бейдж + нижние титры
  - ~45% — **cover-сцена**: тёмный фон, спикер в PiP (правый верх),
    по центру инфографика / карточка / схема / UI

## Титры (captionStyle: `karaoke-box`)
- Нижняя треть, 2–4 слова за раз, UPPERCASE, жирный гротеск.
- Тёмная полупрозрачная плашка (rounded) вокруг фразы.
- Текущее слово: **жёлтый фон `#F5E14B` + чёрный текст**.
- Остальные слова: белые на тёмной плашке.

## Верхние бейджи (поверх спикера, `cover:false`, `layout:third`)
Когда спикер полный кадр — сверху появляется:
1. Жёлтая rounded-карточка с крупным значением (`×10`, `1 000 000 ₽`, `МЕТОД`)
2. Под ней чёрная pill-подпись (`оборот компании`, `в месяц`)

Шаблоны motion: `metric-callout`, `number-counter`, `kinetic-type`,
`notification-toast` с `accent: "#F5E14B"`.

## Cover-сцены (`data.cover:true`)
На мысль/тезис — полный уход на тёмно-синий фон + центральный контент:
| Смысл фразы | template | data-пример |
|---|---|---|
| Цифра / метрика | `number-counter` / `metric-callout` | value, label, accent |
| Сравнение лет / рост | `fake-dashboard-bars` / `stat-grid` | bars / items |
| Процесс / воронка | `arrow-flow` / `timeline-steps` | steps |
| Проблемы «как все» | `checklist-reveal` | items + icons (bolt) |
| UI / квиз / форма | `phone-mockup` / `fake-terminal` | lines / title |
| Тезис / цитата | `quote-card` / `big-statement` | text / lines |
| Оффер / цена | `price-tag` | price, old, label |

Тег контекста (год, клиент, тема) — `pill-row` или `notification-toast`
в `data` cover-сцены / отдельный короткий insert.

## Акценты (accents.json)
- 1 акцент на 3–5 сек: цифры, ключевые слова, панчи, CTA.
- Текст капсом 1–3 слова.

## Цвета
- Accent yellow: `#F5E14B`
- Ink on accent: `#0A0C14`
- Cover bg: `#0A0C14` / navy
- Tag accents: `#22D3EE`, `#34D399`, `#FB7185` (чередовать)

## Не делать
- Длинные участки только с титрами без вставок.
- Cover на каждую секунду (усталость) — максимум ~половина мыслей.
- Дублировать на титрах слова, уже показанные крупной motion-вставкой.
