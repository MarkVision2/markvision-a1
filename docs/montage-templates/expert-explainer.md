# Montage style: Expert Explainer (логика референса)

Два одинаковых ролика-кейса (9:16, ~90–110 с). Суть не в «титрах на говорящей голове»,
а в том, что **каждая мысль = отдельная сцена с визуалом**, который её иллюстрирует.

## Главный принцип

| Если спикер говорит… | На экране появляется… |
|---|---|
| Боль / проблема («игнорят», «дорого», «пропадают») | Крупная цифра % + красные тег-боксы |
| «После нас» / успех | Зелёный gauge/кольцо + чеклист с ✓ |
| Раньше vs сейчас (деньги) | Столбцы «Раньше» (серый) / «Сейчас» (неон) |
| Процесс / что сделали | Вертикальный flowchart, активный шаг светится |
| Углы креативов | Стопка цветных карточек (боль / цена / результат) |
| Плохой креатив | Карточка оффера + сетка тегов («дешевая») |
| Цель / тезис | Полный кадр спикера + **красная шапка-заголовок** |
| Итог / выручка | Огромное число (15–25) + подпись в pill |

Титры (караоке) **всегда внизу**, в том числе на cover-сценах.

## Два режима кадра

### A. Cover / explainer (~55–65% времени мысли)
1. Тёмный navy/чёрный фон + цветной glow
2. Спикер в **PiP правый верх** (rounded)
3. **Тег контекста** левый верх (цветная pill): «У КЛИЕНТА ПОСЛЕ НАС», «А ЧТО СДЕЛАЛИ МЫ»…
4. **Центр = мысль** (метрика / схема / сравнение / UI)
5. Караоке-титры снизу

→ в Remotion: `data.cover=true` + подходящий template + `notification-toast`/`pill-row` как тег.

### B. Speaker / thesis (~35–45%)
1. Спикер на весь кадр
2. Крупный цветной заголовок по груди (часто **красный**): «ЦЕЛЬ ТАРГЕТОЛОГА: …»
3. Караоке-титры снизу
4. Иногда жёлтый бейдж метрики сверху

→ `cover:false` + `big-statement` / `kinetic-type` / `metric-callout`, `layout:third`.

## Титры (`karaoke-box`)
- Тёмная плашка, 2–4 слова, UPPERCASE
- Текущее слово: жёлтый `#F5E14B` фон + чёрный текст
- **Не прятать** титры во время cover-сцен

## Ритм
- 1 визуальная сцена на **3–5 сек** мысли, без «пустых» кусков >5 сек
- Cover и speaker **чередуются** по смыслу (не залипать на одном режиме)
- Акцент-слова / панч-зумы на цифрах и CTA

## Цвета по смыслу
- Проблема / «плохо» → красный `#FB7185` / `#EF4444`
- Успех / «после нас» → зелёный `#34D399`
- Метрика / акцент слова → жёлтый `#F5E14B`
- Тег контекста → жёлтый / зелёный / cyan / красный (менять по сцене)
- Фон cover → `#0A0C14` + glow цвета сцены

## Маппинг → motion templates
| Сцена | template | data |
|---|---|---|
| % + подпись | `number-counter` / `metric-callout` | value, label, accent |
| % + теги боли | `stat-grid` или `checklist-reveal` | items |
| Кольцо + ✓ | `gauge` + `checklist-reveal` | value, items, icons:check |
| Раньше/сейчас | `fake-dashboard-bars` / `vs-compare` | bars / leftItems+rightItems |
| Flowchart | `timeline-steps` / `arrow-flow` | steps |
| Углы креатива | `checklist-reveal` / `pill-row` | items + accents |
| Карточка+теги | `price-tag` + `pill-row` | price, label, items |
| Тезис на спикере | `big-statement` | lines, accent red |
| Тег сцены | `notification-toast` | title, accent |

## Не делать
- Только титры без визуала мысли
- Cover реже 40% на кейс-ролике
- Прятать караоке на cover
- Один и тот же template подряд без смены цвета/типа
