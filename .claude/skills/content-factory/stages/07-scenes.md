# Этап 7. Сцены и анимация + критик сцен

**Исполнитель:** сильная модель (планирование) + критик отдельным субагентом. **Вход:**
`scripts/<id>.md` (блок `scenes`), `avatar/<id>.words.json`, `scenes.md`, `accounts.json`
(тема аккаунта). **Выход:** `scenes/<id>.json` — пропсы композиции Remotion.

## Правила
1. **Тайминги сцен — из `words.json`**, не из расчётной длины текста. Граница сцены = начало
   первого слова тезиса.
2. **Четыре раскладки** (`scenes.md`): `avatar_bottom` (аватар снизу, контент сверху),
   `content_full` (контент на весь экран, аватар скрыт), `avatar_circle` (круглый аватар поверх
   контента), `avatar_full` (аватар на весь экран, анимация над ним). Других нет.
3. **Цвета только из темы аккаунта** (`accounts.json` → `theme`). Общие компоненты не имеют
   захардкоженных цветов: чёрный «по умолчанию» в общем компоненте однажды покрасил всю
   пачку в один цвет.
4. **Каждый тезис/кейс сценария получает свою сцену.** Пропущенная сцена — самая частая ошибка.
5. Размеры: круглый аватар ≥ 28 % ширины кадра; текст на экране ≤ 2 строк, кегль по
   `docs/brandbook.md`; безопасные поля 9:16 (верх 220 px, низ 320 px под интерфейс площадки).
6. Композиция всегда 1080×1920.

## Формат `scenes/<id>.json`
```json
{"id":"…","account_id":"…","theme":{"bg":"#…","accent":"#…","text":"#…"},
 "avatar":"avatar/<id>.mp4","words":"avatar/<id>.words.json",
 "scenes":[{"from_ms":0,"to_ms":4200,"layout":"avatar_full","title":"…"},
           {"from_ms":4200,"to_ms":14000,"layout":"avatar_bottom","title":"…","bullets":["…"],"visual":"stat|list|quote|compare"}]}
```

## Критик сцен (отдельный субагент, `critic.md`)
Проверяет по каждому ролику: (1) все тезисы из `scripts/<id>.md` имеют сцену — `missing_scene`;
(2) все цвета из темы аккаунта — `theme_color`; (3) размеры и поля — `size`; (4) круглый
аватар не под непрозрачным фоном — `overlap`; (5) сумма сцен = длительность аватара ± 100 мс —
`duration_mismatch`; (6) раскладки только из четырёх. Чинит сам, пишет в `critic.log`.

## Чек-лист
- [ ] `scenes/<id>.json` на каждый ролик, валиден против формата.
- [ ] Первая сцена — хук, последняя — CTA.
- [ ] Ни одного цвета вне темы, ни одной раскладки вне четырёх.
