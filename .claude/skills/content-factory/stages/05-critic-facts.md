# Этап 5. Критик фактов и голоса

**Исполнитель:** сильная модель, чистый контекст, роль по `critic.md`. **Вход:** `scripts/*.md`,
`approved.json` (там `source_facts` и транскрипты по ссылке из `trends.json`), `voice.md`,
`project.md`. **Выход:** исправленные `scripts/*.md`, `facts.json`, `critic.log`.

## Что проверять по каждому сценарию
1. **Галлюцинации.** Каждую цифру, множитель («в 5–10 раз»), имя, кейс сверить с
   `source_facts` и транскриптом источника. В практике агент приписал «в 5–10 раз дороже» там,
   где источник давал только качественное утверждение. Нет в источнике → убрать или заменить
   на качественную формулировку. `hallucination`, `auto_fixed: true`.
2. **Проверяемость.** Есть ли в тексте хотя бы одно подтверждение, которое зритель может
   проверить (источник, кейс, цифра с оговоркой откуда). Нет → пометить, переписать абзац.
3. **Голос.** Сверить с примерами из `voice.md`: длина фраз, отсутствие штампов, обращение.
   `voice_mismatch` — переписать фразу, не весь текст.
4. **CTA.** Есть, ведёт на следующий шаг из `project.md`, не продаёт. `missing_cta`.
5. **Одна мысль.** Если в тексте две — оставить ту, что в `seed`.
6. **Длина** по `format.md`. Пересчитать слова.
7. **Сцены** покрывают каждый тезис; раскладки существуют в `scenes.md`.

## `facts.json`
```json
[{"id":"…","claims":[{"text":"…","source":"trends:tt-7312… 0:41","status":"ok|removed|softened"}]}]
```

## Эскалация (только это)
- Факт важен для мысли, в источнике его нет, но он может быть правдой — вопрос человеку:
  «подтвердить источником / убрать».
