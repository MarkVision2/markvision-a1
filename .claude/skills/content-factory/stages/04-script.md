# Этап 4. Сценарии

**Исполнитель:** сильная модель, **один субагент на 5–8 сценариев** (не вся пачка в одном
контексте). **Вход:** `approved.json`, `project.md`, `voice.md`, `format.md`, `antipatterns.md`.
**Выход:** `scripts/<id>.md` на каждый ролик.

## Требования к сценарию
- Длина по `format.md` (по умолчанию 60–90 слов, 25–40 с озвучки).
- **Хук** — первые 1–2 фразы, они же начинают текст. Без «привет, друзья».
- **Одна мысль.** Из `seed` кандидата, не «три совета».
- **Проверяемое подтверждение**: факт, цифра или кейс **из `source_facts`** или из `project.md`.
  Совет без практики не проходит. Если подтверждения нет — так и писать: «по моему опыту…»,
  без цифр.
- **CTA на следующий шаг воронки** из `project.md` (подписка, Telegram, бесплатный материал).
  Никаких «купите», «запишитесь на консультацию» в первом касании.
- Голос по `voice.md`: примеры фраз, запрещённые обороты. Запреты из `forbidden_phrases`
  настроек конвейера тоже действуют.
- **Два варианта текста** на тему (A/B): другой хук, та же мысль. В сборку идёт A, B остаётся
  для пересъёмки, если A отклонён.

## Формат `scripts/<id>.md`
```markdown
# <id> · <topic_key>
seed: <мысль>
source: <url>
facts_used: ["…дословно из source_facts…"]

## A
hook: …
text: … (полный текст озвучки, 60–90 слов)
cta: …
scenes:
  - {t: "0-4", layout: "avatar_full", text_on_screen: "…"}
  - {t: "4-14", layout: "content_top", visual: "что показать", text_on_screen: "…"}
  - …

## B
hook: … / text: … / cta: …

title: до 80 символов
description: 2–4 предложения без обещаний
hashtags: [5–10]
```
Раскладки сцен — из `scenes.md` (4 типа). Каждый тезис текста должен иметь свою сцену.

## Чек-лист
- [ ] Каждая цифра в `text` есть в `facts_used`.
- [ ] Есть hook, cta, ≥ 3 сцены, оба варианта.
- [ ] Ни одного запрещённого оборота из `voice.md` и настроек.
- [ ] Слов в пределах формата (посчитать).
