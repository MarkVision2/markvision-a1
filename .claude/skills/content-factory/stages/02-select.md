# Этап 2. Отбор под тему проекта

**Исполнитель:** сильная модель, чистый контекст. **Вход:** `trends.json`, `project.md`,
`format.md`, `antipatterns.md`. **Выход:** `candidates.json`.

## Что делать
Для **каждого** поста найти «зерно» — одну мысль, которую можно пересказать за 20–40 секунд
говорящей головой без экрана, и решить, подходит ли она аудитории и продукту проекта.

## Правила (каждое закрывает реальную ошибку из практики)
1. **Метка формата ставится фрагменту, а не видео.** Ролик со скринкастом почти всегда содержит
   кусок мысли, который пересказывается без экрана. Ищи его. После этого правила пул кандидатов
   вырос в разы.
2. **Отбирать все подходящие, а не одно лучшее.** Занижение объёма = один ролик в неделю вместо
   пачки. Количество кандидатов динамическое: 10, 20, 50 — сколько нашлось.
3. **Язык источника — не критерий.** Единственный вопрос: переносится ли суть на русскоязычную
   аудиторию проекта по смыслу. Японское и испанское оцениваются одинаково.
4. **Отбрасывать только то, что нельзя сделать без экрана** (обзор интерфейса шаг за шагом,
   код на экране как суть) и то, что не про аудиторию проекта.
5. Дубли тем внутри пачки помечать `topic_key` одинаковым — дальше они разойдутся по дням.

## Формат `candidates.json`
```json
[{"id":"tt-7312…","selected":true,"seed":"одна мысль своими словами, 1–2 предложения",
  "why_fits":"какую боль аудитории из project.md закрывает",
  "format_ok":true,"format_note":"фрагмент 0:40–1:10 без экрана",
  "topic_key":"сеть-аккаунтов-вместо-одного","source_facts":["факт/цифра из источника дословно"],
  "rejected_reason":null}]
```
`source_facts` — только то, что есть в источнике дословно. Это опора для этапа 5.

## Чек-лист
- [ ] Просмотрены все посты из `trends.json`, у каждого есть `selected` и причина.
- [ ] Ни одного отсева по языку.
- [ ] Ни одного отсева по «в видео есть экран» — только по «мысль не существует без экрана».
- [ ] `topic_key` проставлен, похожие темы получили один ключ.
- [ ] Количество `selected` соответствует реальному числу подходящих, не «топ-5».
