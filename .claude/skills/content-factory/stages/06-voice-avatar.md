# Этап 6. Озвучка и аватар

**Исполнитель:** дешёвая модель + скрипты. **Вход:** `scripts/*.md` (вариант A), настройки
проекта (аватар/голос HeyGen из `content_pipeline_settings`, либо голос ElevenLabs из
`src/lib/elevenVoices.ts`). **Выход:** `avatar/<id>.mp4`, `avatar/<id>.words.json`, `cost.json`.

## Два пути
**А. Конвейер MarkVision (по одному ролику, полностью автоматически).**
На каждую тему — `POST /functions/v1/content-pipeline/items` `{project_id, title, description:
<текст A>}` → `POST /items/:id/generate`. Конвейер сам делает сценарий (перепишет — поэтому
передавать готовый текст в `description` с пометкой «использовать дословно») и видео HeyGen,
нормализует и присылает на согласование. Подходит, когда тем ≤ 10 и есть JWT пользователя.

**Б. Пакетный путь (как у автора, пока API-пакет не сделан).**
1. Все тексты A одного аккаунта склеить в один документ, между ними **пауза 5 секунд**
   (в HeyGen/Avatarami — отдельные сцены с тишиной, в ElevenLabs — `<break time="5s"/>`).
2. Сгенерировать одно длинное видео аватара.
3. `node scripts/factory-cut.mjs <long.mp4> avatar/` — режет по паузам ≥ 3 с, именует по порядку
   сценариев из `scripts/` (передать список id через `--ids`).
4. На каждый файл — тайминги слов: `.venv/bin/python pipeline/transcribe.py avatar/<id>.mp4`
   → `avatar/<id>.words.json`. Они нужны этапу 7 для синхронизации сцен.

## Стоимость
Аватар 0,10–0,15 $/с → ролик 25–40 с ≈ 2,5–6 $. Писать в `cost.json` (`{"stage":6,"id":…,"usd":…}`).
Если провайдер отвечает «insufficient credit» — это баланс, не сбой: остановиться и сказать.

## Чек-лист
- [ ] На каждый `scripts/<id>.md` есть `avatar/<id>.mp4` и `words.json`.
- [ ] Длительность аватара в пределах формата; в начале/конце нет обрезанных слов (проверить
  первое и последнее слово в `words.json` против текста).
- [ ] Никакой обработки звука (нормализация/шумодав запрещены), только нарезка по паузам.
