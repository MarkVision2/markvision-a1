# Контент-завод (content-factory)

Оркестратор пачки. Основание — `docs/TZ-content-factory-network.md` (система из двух видео
канала «Вкалывают Роботы»). Читать этот файл первым, дальше — только файл текущего этапа.

## Принципы (не нарушать)
1. **Один этап = один субагент с чистым контекстом.** Никогда не делать всю пачку в одном чате:
   к 20-му ролику модель деградирует и начинает оправдывать свои ошибки.
2. **Критик не участвует в производстве.** Проверяет чужой результат по `critic.md`.
3. **Критик чинит сам.** К человеку возвращается только то, что решить может только человек.
4. **Каждая ошибка → строка в `antipatterns.md` проекта** и в чек-лист этапа.
5. **Детерминированное — скриптами**, не моделью: нарезка озвучки, проверки сборки, раскадровка.
6. **Один формат на старте**: аватар поверх анимации 9:16, 20–40 с, без скринкастов.
7. Ничего не рендерить и не публиковать без явной команды на воротах (этап 8).

## Файлы проекта (обязательный минимум)
Лежат в `work/factory/<project>/` (в git не попадают). Если их нет — сначала создать по шаблонам
из `templates/` вместе с пользователем (10–15 минут вопросов), иначе агент делает усреднённый контент.

| Файл | Что внутри |
|---|---|
| `project.md` | что продаём, кому, воронка, следующий шаг после ролика, project_id MarkVision |
| `voice.md` | голос автора: примеры фраз, запрещённые обороты, ритм |
| `format.md` | формат: длительность, раскладки, что отбрасываем |
| `antipatterns.md` | журнал ошибок с правилами (пополняется критиками автоматически) |
| `scenes.md` | правила раскадровки и 4 раскладки |
| `accounts.json` | аккаунты сети: id из MarkVision, тема (цвета), персона |

## Структура пачки
```
work/factory/<project>/batches/<YYYY-MM-DD>-<n>/
  trends.json        этап 1  — собранные источники
  candidates.json    этап 2  — отбор с «зерном» мысли и меткой формата
  approved.json      этап 3  — утверждённый список после критика
  scripts/<id>.md    этап 4  — сценарии (hook, текст, CTA, сцены)
  facts.json         этап 5  — что проверил критик фактов, что убрал
  avatar/<id>.mp4    этап 6  — аватар + words.json (тайминги)
  scenes/<id>.json   этап 7  — пропсы сцен для Remotion
  storyboard.html    этап 8  — раскадровка всей пачки для модерации
  out/<id>.mp4       этап 9  — финал + publish.json
  critic.log         все находки критиков (stage, kind, auto_fixed, note)
  cost.json          стоимость по этапам
```

## Этапы и субагенты
Каждый этап запускается как **отдельный субагент** (Agent tool) с промптом: «прочитай
`.claude/skills/content-factory/stages/0N-*.md` и файлы проекта, вход — <путь>, выход — <путь>».
Критики — отдельные субагенты с `critic.md` + файлом этапа. Модели: этапы 1, 6, 9 — дешёвая
модель (перенос данных, скрипты); 2, 4, 7 и все критики — сильная модель.

| # | Этап | Файл | Критик |
|---|---|---|---|
| 1 | Сбор трендов | `stages/01-collect.md` | — |
| 2 | Отбор под тему, «зерно» мысли, метка формата | `stages/02-select.md` | — |
| 3 | Критик отбора → `approved.json` | `stages/03-critic-select.md` | да |
| 4 | Сценарии (тезисы + варианты + CTA + сцены) | `stages/04-script.md` | — |
| 5 | Критик фактов | `stages/05-critic-facts.md` | да |
| 6 | Озвучка и аватар, нарезка, тайминги | `stages/06-voice-avatar.md` | — |
| 7 | Сцены и анимация + критик сцен | `stages/07-scenes.md` | да |
| 8 | Модерация человеком (ворота) | `stages/08-review.md` | — |
| 9 | Сборка, проверки, раскладка по сети | `stages/09-assemble-publish.md` | — |

## Команда запуска
«Сделай пачку роликов для <проект> за <период>» →
1. Проверить файлы проекта; создать пачку `batches/<дата>-<n>/`.
2. Этапы 1–7 подряд субагентами без остановок (критики чинят сами, эскалации копятся
   в `critic.log` с пометкой `escalated`).
3. Остановиться на этапе 8: показать `storyboard.html` и список эскалаций. Ждать команды.
4. По команде — этап 9: сборка, проверки, `markvision_upload_media` + `markvision_create_publication`
   (без target) на каждый ролик, затем один `markvision_distribute` на всю пачку с `topic_key`.
5. Итог: сколько роликов, стоимость, что ушло в какие аккаунты, что осталось в `unassigned`.

## Композиция
`remotion/src/ReelsAvatar.tsx` — аватар поверх анимации, 1080×1920, четыре раскладки
(`avatar_full`, `avatar_bottom`, `avatar_circle`, `content_full`). Одно видео аватара
смонтировано на всю композицию и меняет только геометрию — звук не рвётся на стыках сцен.
Геометрия и проверки — `remotion/src/avatarLayout.ts` (тесты `src/test/avatarLayout.test.ts`),
образец пропсов — `remotion/props/reels-avatar.example.json`.

## Скрипты
- `scripts/factory-cut.mjs <long.mp4> <outdir>` — режет длинное видео аватара по паузам ≥ 3 с.
- `scripts/factory-check.mjs <video.mp4>` — длительность видео = звук (±0,1 с), 1080×1920, 
  размер, наличие звука. Выход не 0 = ролик не готов.
- `scripts/factory-storyboard.mjs <batch_dir>` — собирает `storyboard.html` из `scenes/*.json`.
